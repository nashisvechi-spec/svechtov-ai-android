# Артель Свечтовъ AI
Android MVP with Yandex AI Studio integration. Build: Actions → Build Android APK → Run workflow. Download SvechtovAI-debug-apk from artifacts.

Settings: enter Yandex API key and model URI on the device. API key is encrypted using Android Keystore. Import normalized JSON snapshot using the system file picker (Google Drive supported as document provider). This is not yet automatic Drive sync; production database is never modified.
